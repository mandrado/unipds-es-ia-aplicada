# Installation

## Installing the LangGraph CLI explicitly as a development dependency

```bash
npm install
npm install @langchain/langgraph@latest @langchain/core@latest
npm install -D @langchain/langgraph-cli@latest --legacy-peer-deps
```

## Upgrading the LangGraph CLI and the core library to satisfy the Studio tracing requirements

```bash
pip install --upgrade langgraph-cli langgraph
```
